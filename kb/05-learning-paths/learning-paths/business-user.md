# Business User Path

Use this path if your goal is to understand the system, request changes, review progress, or confirm what has already been agreed.

## Start Here

1. Read `README.md` for the project shape.
2. Read `kb/05-learning-paths/USER-GUIDE.md` for the navigation model.
3. Ask the Guide agent for a system walkthrough in plain language.

## What To Use For Common Tasks

- Understand what a feature is supposed to do: read the relevant folder under `kb/features/`.
- Ask where a request belongs: use Orchestrator.
- Turn an idea into explicit requirements: use BA.
- Check whether something is proven: read `testing-report.md` for the feature.

## Working Rule

If something was said in chat but is not recorded in the KB, treat it as a working conversation rather than approved project truth.
